## 從史書借三個問題

| 史學上的問題 | 對 Chronicle 的具體要求 |
| --- | --- |
| 同一件事有不同記載，為何採此說？ | 《資治通鑑考異》卷三十並列不同實錄，也記下曆日或來源立場如何影響取捨。對一個方法分歧，agent 應列出「同時代文件說了什麼」「另一種讀法」「哪一段支持目前判讀」，使讀者能從原文推翻解釋。[《考異》卷三十](https://www.shidianguji.com/zh/book/CADAL01033465/chapter/1l4cevftedlie) |
| 改變的究竟是方向、速度，還是只換了稱呼？ | Seixas 與 Morton 把轉折放在連續與變化中考察，也把能揭示問題的事件列入歷史重要性。主題詞首次出現可以啟動調查；判定轉折需要交代前後的方法、問題或採用群體有何不同，哪些工作仍延續。[Guideposts to Historical Thinking](https://historicalthinking.ca/sites/default/files/files/docs/Guideposts.pdf) |
| 當時誰看得到哪些選擇？哪些資料沒有進入我們的敘事？ | Butterfield 提醒讀者注意由現在倒推歷史的選擇偏差。美國歷史學會要求歷史教科書揭示選材依據與缺口、呈現有史料依據的爭議。對本工具，測量可分為當年樣本中的文章分布、同時代文件記錄的採用，以及後來的回顧或累積引用。三者要分別定年。[Butterfield 原著節選](https://www.clarehall.cam.ac.uk/wp-content/uploads/2022/08/Butterfield_selected.pdf) · [AHA 史書教材評估指引](https://www.historians.org/resource/guidelines-for-the-preparation-evaluation-and-selection-of-history-textbooks/) |

## 人工耳蝸的兩種「單通道／多通道」

固定主題 `Cochlear implants`，明列以下三個 PMID，透過專案的 PubMed adapter 抓 3/3 筆書目，使用相同資料比較政策修正前後。三篇都沒有作者關鍵詞。這是有意挑選來找盲點的小樣本，無法估計整個領域的主流或工具的召回率。

| 書目 | 文件可支持的判斷 |
| --- | --- |
| 1985，PMID 3878092 | 作者比較六種植入**裝置**，單通道和多通道各三種。這份早期比較能指認當時觀察到的選項。[原研究摘要](https://pubmed.ncbi.nlm.nih.gov/3878092/) |
| 1986，PMID 3753836 | 在同款八電極植入裝置上比較五種**訊號處理策略**，包括兩種單通道、三種多通道，受試者兩位。與前篇共用詞彙，所比較的技術層次不同。[原研究摘要](https://pubmed.ncbi.nlm.nih.gov/3753836/) |
| 1988 年 NIH 會議，1989 年期刊版 PMID 2642379 | PubMed 期刊紀錄無摘要。另查 NIH 聲明原件，Introduction 把選用哪種裝置列為當時爭議，第二題比較設計的優缺點，也討論病人選擇與測驗限制。可寫「至少在 1988 年這已是明載的爭點」。爭議開始的年份及各地採用比例仍待取證。[期刊紀錄](https://pubmed.ncbi.nlm.nih.gov/2642379/) · [NIH 聲明原件](https://files.eric.ed.gov/fulltext/ED350771.pdf) |

原版把三筆都歸入 Other Studies。本輪補認 PubMed 的正式出版類型 `Consensus Statement` 後，結構是 Other Studies 兩筆、Guidelines & Practice 一筆，仍屬研究階段備援分類。新版地圖回傳零組語意分岔候選，狀態為 `insufficient_signal_provenance`；同時，`sources_for_review` 列出兩篇比較研究和一份共識聲明，附 entry ID、證據 ID、日期與實際命中的出版類型。即使自動分組無法認出分歧，agent 仍能循當代文件找到爭點。若要追問聾人社群當時如何看待這些選擇，還須另尋該群體的同期材料。這三個 PMID 可用以下呼叫重跑。

```python
build_research_chronicle(topic="Cochlear implants",
                         pmids=["3878092", "3753836", "2642379"],
                         output="chronicle_map")
```

## 什麼能寫進正文

- **分歧。** 若同一篇有日期的文獻有兩條已選索引訊號，後來可各找一篇只帶其中一條訊號的不同文獻，地圖會提供可回查的候選。讀者應檢查當時是否在解同一問題、有無直接比較，以及兩條路是否更早就已並行。方向、立場與影響需要可定位的史料。本輪沒有建立文獻間的因果或引文邊。
- **關鍵文章。** 全域排序保留候選的識別碼與已存評分依據。每條能核實歸屬的非空分支另取一篇供閱讀，讓篇數少的路線有閱讀入口。研究者可按問題區分首提、實作、反例、當時的比較和後來採用。為一項判斷列出當代文件與段落，也說明它涵蓋的地區、研究群體與期間。
- **主流和支線。** 每條線每年直接歸屬的事件數，可除以該版同年全部事件數。無日期、來源截斷、同篇多重標引、查詢與納入範圍都會影響解讀。若要稱某時某地「廣為採用」，應找有母數的使用調查、採購或登錄紀錄等；共識文件可以證明某委員會在某年討論或建議了什麼。若要稱某條線「影響了後來方法」，另找作者明述採用、修改或反駁的段落。

## 下一輪驗收

凍結一個主題與截止年，請兩位評閱者在看工具輸出前各自列出同期有據的分歧、仍延續的替代方案及關鍵史料，再保留兩人不同的解讀。用同一批書目比較舊版地圖、加入候選與文件閱讀入口的版本。逐項量「找回哪幾個已知分歧」「把共詞誤稱分歧幾次」「稀少路線能否找到代表作」「是否誤用截止日以後的引用、後續採用或今日補標作為當年的證據」。當代來源與後見回顧分開評分。

如要測引用排序對少數反證的影響，Greenberg 已公開一個特定生醫主張的引用網絡，含逐篇引文與原句。可從中抽取原始證據與轉述，檢查 agent 是否找回少被引用的反證、是否把多次轉述當成獨立驗證。這是第二個獨立案例，保留到方法與評分表凍結後再測。[研究全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC2714656/) · [作者補充材料](https://www.bmj.com/content/bmj/suppl/2009/07/21/bmj.b2680.DC1/gres611285.ww1.pdf)
