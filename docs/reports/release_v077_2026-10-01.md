# v0.7.7 — test and CI renovation

Scope: replace low-signal tests with exercised workflows, move deterministic
checks before push, and verify the exact release artifacts. Baseline master was
`c8ac9496a9070e56874c55697e996c63dcb2f8ce`, fetched before editing. Runtime APIs,
provider limits and the 41-tool public surface are unchanged.

## Phases and acceptance criteria

1. **Baseline and review:** run the original suite, inspect candidate tests and
   compare default CI/release commands. Completed: 4,914 passed, 23 skipped,
   30 live tests deselected in 125.23 s on local Python 3.10. All 207 current test
   files were scanned for empty/tautological tests; selected coverage-named,
   startup and workflow tests were read semantically. This is not a claim of a
   semantic review of every remaining test.
2. **Real smoke before removal:** production stdio/HTTP calls, restart/isolation,
   provider JSON/XML over loopback HTTP, actual notes/CSL/session output, shared
   artifact install and sdist parity. Completed: 15 smoke cases passed in 18.09 s.
   Test data are synthetic; no external literature API was called.
3. **Remove only with replacement evidence:** completed 64 explicit removals in
   the [ledger](test_renovation_removals_v077.json), including 3 empty `pass` tests,
   2 tautologies, import/registration-only duplicates, mock-only “E2E” scenarios,
   and permanently skipped retired interfaces. Exception, concurrency, quota,
   malformed-input, isolation and security regressions remain in full pretest.
4. **Local/cloud split:** `pretest` aliases the full pre-push gate; JSON evidence
   records current execution without success caching. Ordinary CI runs 15 real
   smoke cases per Ubuntu/Windows environment instead of the previous 254-case
   mixed unit/docs subset on Ubuntu. Tag verification promotes the exact tested
   wheel/sdist and exercises the real container, after successful mainline CI.
   Deterministic lint/types/docs/full regressions run locally; manual compatibility,
   renderer and live-provider workflows remain available.
5. **Documentation and release:** testing policy, website/Wiki navigation, MEM,
   segmented commits, merged mainline and v0.7.7 publication. Hosted verification
   and publication evidence are recorded after the workflows actually finish.

## What changed in the evidence

The old “E2E” suite called prefilled `AsyncMock` instances or inspected local
Python dictionaries, including a “retry” case that only checked the mock raised.
The replacement sends real HTTP requests through production Europe PMC and
Biopython clients, parses JSON/JATS/PubMed XML, performs MCP calls and inspects
persisted Markdown/CSL/session data. It also rejects malformed JSON and HTTP 401
as provider failures rather than reporting successful empty searches.

The old wheel checks independently built/installed twice. The shared fixture
builds one distribution pair (or receives the exact release pair), compares an
sdist rebuild with every wheel entry and installs production dependencies once.
Tests execute real console scripts from outside the checkout. Readiness, tool
registry/schema, a rejected write and one repaired retry, persisted writes,
process restart, data-root isolation and deletion are all asserted. The browser
broker's missing-token startup refusal is checked without installing Chromium.

Container verification previously only ran `--help`. It now starts the default
image command, checks the effective non-root UID, health/readiness, MCP list/call,
Host/Origin rejection and durable writes. Docker is unavailable in the local
environment, so the hosted container result must be recorded separately.

Two bounded fault injections in temporary artifacts were also detected: a wheel
with an extra file failed sdist/wheel parity; an installed HTTP console forced to
exit 23 failed readiness immediately. The temporary console was restored. These
are detector checks, not an exhaustive mutation score.

## Validation and limits

- Initial integrated full gate: 4,861 passed, 19 skipped, 31 deselected, 2 SDK
  deprecation warnings in 125.82 s; lint/format/async/layout/publication/inventory
  and mypy (442 files) passed. Of the deselections, 30 are live API cases and one
  is the explicit container check. Four obsolete permanent skips were removed.
- The full suite timing is effectively unchanged from baseline; no local speedup
  is claimed. The improvement is stronger assertions, one shared installation,
  fewer default cloud cases and removal of a repeated full suite on tag publish.
- Offline fixtures cannot prove provider uptime, WAN performance, browser login,
  agent cost or research quality. Independent CI is retained because local hooks
  can be bypassed. JSON reports are descriptive evidence, never trusted skip tokens.
- Final local and hosted results will be appended with the publication receipt.

and responsibilities. The removal ledger and dated measurements remain historical.
